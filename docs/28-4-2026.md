## 3. AI GATEWAY v2 — UPGRADE YANG SUDAH DILAKUKAN

### Model Upgrade
| Sebelum | Sesudah |
|---------|---------|
| `anthropic/claude-3.5-haiku` (8K output) | **`anthropic/claude-haiku-4.5`** (64K output, thinking ✅) |
| Max tokens 4096 | **Max tokens 8192** |

### Fitur Baru yang Ditambahkan
1. **Reasoning/Thinking** — `reasoning: { effort, maxTokens, exclude }`
   - Effort levels: `xhigh`, `high`, `medium`, `low`, `minimal`, `none`
   - Untuk Anthropic: `maxTokens` min 1024, max 128000
   - `exclude: true` → model berpikir tapi reasoning tidak dikembalikan

2. **Web Search via Server Tool** — menggantikan plugin `web` yang deprecated
   - Menggunakan `openrouter:web_search` server tool
   - Field: `enableWebSearch: true`

3. **IoT Context Injection** — `SessionSummary` table
   - Edge AI di Pi merangkum sesi → push ke cloud
   - AI chat auto-inject 5 sesi terakhir sebagai context
   - Fields: `deviceId`, `includeIotContext`

### File yang Diubah (AI Gateway v2)
```
prisma/schema.prisma              → + SessionSummary model + relations
src/modules/ai-gateway/
  ├── openrouter.client.ts        → + reasoning, OpenRouterToolDef, response types
  ├── dto/ai-gateway.dto.ts       → + ReasoningDto, deviceId, enableWebSearch
  └── ai-gateway.service.ts       → model upgrade, reasoning, IoT context, web search
.env                              → claude-haiku-4.5, max tokens 8192
```
